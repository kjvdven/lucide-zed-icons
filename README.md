# Lucide Icons for Zed

A file and folder icon theme for [Zed](https://zed.dev) built from [Lucide](https://lucide.dev): round caps, Lucide's 24×24 grid, and spacing that matches the official set. Two variants, tuned for [Tokyo Night](https://github.com/folke/tokyonight.nvim):

- **Lucide Dark** – icon colour `#787C99`, the same muted colour Zed uses for its own icons in Tokyo Night
- **Lucide Light** – icon colour `#565A6E`, with Tokyo Night Light's blue undertone

Slightly smaller and thinner than pure Lucide, to match Zed's own icons.

![File tree in Lucide Dark and Lucide Light](images/preview-tree.png)

## Design rules
- **Bare symbol** = a language or the thing itself: `JS`, `TS`, `GO`, `M↓` (Markdown), `#` (CSS), `{ }` (JSON), elephant (PHP), gem (Ruby), devil horns (Metal shaders – \m/), snowflake (Nix), moon (Lua), λ (Haskell), chef's hat (mise – as in *mise en place*), image, font…
- **File with a corner symbol** = a file that wraps something else: templates (HTML/XML `<>`, Blade `@`, ERB gem).
- Corner symbols use Lucide's standard corner size (~10×10), so they weigh the same.
- Every file type Zed knows has a Lucide icon; languages without their own icon fall back to a generic `<>` (`code`), never to Zed's default icons.
- Generic symbols only – no brand logos.

## Install (dev extension)
1. Put this folder somewhere permanent – Zed loads a dev extension straight from it.
2. Command palette → `zed: install dev extension` → choose this folder (the one containing `extension.toml`).
3. Command palette → `icon theme selector: toggle` → pick *Lucide Dark* or *Lucide Light*.

Follow your system appearance in `settings.json`:
```json
"icon_theme": { "mode": "system", "light": "Lucide Light", "dark": "Lucide Dark" }
```

## Change or extend
Everything is generated by `build.py` from a clone of the Lucide repo:
```sh
git clone --depth 1 https://github.com/lucide-icons/lucide.git /tmp/lucide
python3 build.py /tmp/lucide
```
Then open `zed: extensions` and click **Rebuild** on Lucide Icons. If something fails, check `zed: open log`.

Settings at the top of `build.py`:

| Setting | What it does |
|---|---|
| `APPEARANCES` | Theme names and the fixed icon colour per variant |
| `PADDING` | Extra room around the 24px grid; higher = smaller and thinner icons (0 = pure Lucide) |
| `STROKE_WIDTH` | Line width; Lucide's default is `2` |
| `CHOICES` | Alternatives for Blade, ERB and Markdown (kept in `custom/`) |
| `FILE_ICONS`, `FILE_SUFFIXES`, `FILE_STEMS`, `NAMED_DIRS`, `ZED_KEYS` | Which icon goes with which file or folder |

Custom icons (JS/TS/GO and M↓ lettering, Blade/ERB/HTML files, the framed Markdown mark as an alternative, open variants of named folders) live in `custom/`.

### Why fixed colours?
- Zed renders icon-theme SVGs as images, so they can't inherit the editor theme's colour or react to hover.
- `build.py` bakes in a fixed colour per variant; change it in `APPEARANCES` for other themes.
