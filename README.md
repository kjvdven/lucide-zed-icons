# Lucide Icons for Zed

A file and folder icon theme for Zed built from [Lucide](https://lucide.dev): 2px strokes, round caps, 24×24 grid. Two variants: **Lucide Dark** and **Lucide Light**.

## Design rules
- **Bare symbol** = a language or the thing itself: `JS`, `TS`, `#` (CSS), `{ }` (JSON), elephant (PHP), gem (Ruby), image, font…
- **File with a corner symbol** = a file that wraps something else: templates (HTML `<>`, Blade `@`, ERB gem).
- Corner symbols use Lucide's standard corner size (~10×10), so they weigh the same.
- Every file type Zed knows has a Lucide icon; languages without their own icon fall back to a generic `<>` (`code`), never to Zed's default icons.
- Generic symbols only - no brand logos.

## Install (dev extension)
1. Open the command palette → `zed: install dev extension` → choose this folder.
2. Command palette → `icon theme selector: toggle` → pick *Lucide Dark* or *Lucide Light*.

Tip: let it follow your system theme in `settings.json`:
```json
"icon_theme": { "mode": "system", "light": "Lucide Light", "dark": "Lucide Dark" }
```

## Change or extend
Everything is generated by `build.py` from a clone of the Lucide repo:
```sh
git clone --depth 1 https://github.com/lucide-icons/lucide.git /tmp/lucide
python3 build.py /tmp/lucide
```
Edit the mappings (`FILE_ICONS`, `FILE_SUFFIXES`, `FILE_STEMS`, `NAMED_DIRS`) or the stroke colours in `APPEARANCES`, then rebuild. Custom icons (JS/TS lettering, Blade/ERB options, open variants of named folders) live in `custom/`.
